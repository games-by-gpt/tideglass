# Third-party software

- Three.js (MIT), https://github.com/mrdoob/three.js — bundled 3D renderer.
- @arcadible/sdk (Apache-2.0), https://developer.arcadible.com/references/arcadible-sdk — bundled save integration.
- Vite (MIT), Playwright (Apache-2.0), Arcadible CLI — development tools only.

No external images, fonts, music, models, or textures are used. All world meshes, shaders, sounds, interface elements, and store assets are created by this project.

Full runtime dependency licenses are included in `public/licenses/` and in every deployed build.
